# Self-hosted fonts

Libre Baskerville and Montserrat are distributed under the SIL Open Font License 1.1. Their licence files are retained here. These Latin WOFF2 variable fonts were downloaded from Google Fonts on 9 October 2026. Libre Baskerville is used at 400; Montserrat uses 400–600. Both load with `font-display: swap`.

Sources: https://fonts.google.com/specimen/Libre+Baskerville and https://fonts.google.com/specimen/Montserrat. There are no Google Fonts requests from the deployed website. Add language subsets if adapting for non-Latin copy.
